-self의 의미
현재 메서드를 호출한 객체 자신을 나타냄
메서드를 정의할 때는 self를 적지만, 호출할 때는 직접 전달하지 않습니다.

- 속성
객체가 가지고 있는 데이터
self.name, self.score가 속성으로 분류된다.
객체를 만든 뒤 속성을 읽거나 변경할 수 있다.

- 메서드
클래스 안에 정의된 함수
객체의 속성을 사용해서 동작한다.

	- 속성을 변경하는 메서드
	self.score += amount와 같이 속성을 변경 할 수 있다.

init
객체가 만들어질 때 자동으로 실행되는 메서드
student = Student("민수", 90) 이 객체를 만드는 순간

self.name = "민수"
self.score = 90

이렇게 설정이 된다.

인스턴스 변수
self.name, self.score처럼 객체마다 따로 저장되는 변수를 인스턴스 
변수라고 한다.

	-클래스 변수
	클래스 본문에 직접 정의되어 모든 객체가 공유하는 것.

한 객체를 수정해도 다른 객체에는 영향을 주지 않는다.

상속
시존 클래스의 기능을 물려받아 새로운 클래스를 만드는 기능.
Q.상속은 그냥 클래스가 여러개면 순차적으로 다 상속 받는 건가?

	- super()
	부모 클래스의 기능도 사용하면서 자식 클래스의 기능을 추가 하는 방법
	super().__init__(name) 이런 식으로 부모 클래스의 생성자를 실행한다.
	(__init__ 은 부모 클래스)

메서드 오버라이딩
부모에게 물려받은 메서드를 자식 클래스에서 재정의하는 것

- class 핵심 구조
class 클래스이름:
    클래스변수 = 값

    def __init__(self, 초기값):
        self.속성 = 초기값

    def 메서드(self, 값):
        self.속성을 사용하거나 변경

사용할 경우:
객체 = 클래스이름(초기값)
객체.메서드()
객체.속성
